# ONE TAKE GAME #009 — キャットバイにゃーライト

- **英字名**：CatByNyaLight
- **URL / リポジトリ名**：`cat-by-nyalight`
- **Model**：GPT-5.6 Sol（企画指定の表記）
- **構成**：HTML / CSS / Vanilla JavaScript。外部ファイルの読み込み、ビルド、サーバー、ライブラリは不要です。

## 遊び方

ねずみを操作して屋敷のチーズ **3個** を食べ、開いた巣へ帰る見下ろし型ステルスゲームです。チーズは各エリアの候補地点から毎回変わります。画面端の黄色い矢印が次の目的地方向を示します。

- **スマートフォン**：左下のスティックで移動。右下の `DASH` を押している間ダッシュ。
- **PC**：WASD / 矢印キーで移動。Shift / Spaceでダッシュ。マウスで床をクリックして移動先を指定することもできます。
- **食事**：チーズの近く（45ワールド単位以内）で立ち止まると自動で食べます。約6.25秒の食事進行にスキルチェック時間が加わります。逃げると進行が少し戻りますが、ゼロにはなりません。
- **スキルチェック**：円の針が緑の範囲に入ったところで画面をタップ／クリック。黄色い細い範囲ならPERFECTで進行ボーナス。ミスすると少し巻き戻り、猫に聞こえる可能性のある物音が発生します。PCではSpace / Enterも使用可能。
- **ダッシュ**：移動速度が約1.87倍。スタミナを消費し、大きな足音で猫の注意を引きます。離すと少し遅れて回復し、使い切ると一定量回復するまで使用不可。
- **クリア**：チーズ3個を食べると巣が開き、接触すると脱出成功。猫に接触するとゲームオーバー。

## 猫AI

猫は複数の巡回地点を選び、障害物を迂回して移動します。前方扇形と至近距離の全方向に視界があります。家具・壁は視線を遮ります。発見すると短い警告のあと追跡し、視界が切れると最後に見た場所を捜索してから巡回に戻ります。ダッシュや食事音を距離に応じて調査しますが、壁越しに常時位置を追跡することはありません。

## 公開方法（GitHub Pages）

1. GitHubに公開リポジトリ `cat-by-nyalight` を作成。
2. このフォルダの `index.html`、`style.css`、`game.js`、`README.md` をリポジトリのルートにアップロード。
3. リポジトリの **Settings → Pages** から **Deploy from a branch**、`main`、`/(root)` を選んで保存。
4. 公開URL：`https://<ユーザー名>.github.io/cat-by-nyalight/`（ユーザー名を置換）。

既存のGitHub Pages内のサブディレクトリとして置いても動作します。Web Audio APIの効果音はブラウザのユーザー操作後にのみ再生されます。音のON/OFF、クリア最短記録はブラウザ内に保存されます。

## テスト／制限

- 内部テスト用に `index.html?test=1` で `window.__catGameTest` を公開します（通常時は無効）。
- スマートフォンブラウザでは仮想スティックの触り心地や音量が機種によって異なります。外部音声やBGMはありません。
- クリア率は実プレイヤー統計ではありません。テストによる挙動確認と、実プレイでの難易度は区別してください。
